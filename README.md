# Prompt Forge

Build a premium, modern, futuristic AI website builder SaaS frontend inspired by the overall experience and quality of Fully Emergent.

IMPORTANT:

Build ONLY the frontend/UI.

Do not implement real backend functionality.

Use mock data and simulated interactions where necessary.

Do NOT copy Fully Emergent's branding, logo, text, or exact design. Create an original product and visual identity.

The final result should feel like a polished, production-ready AI SaaS platform.
